# Java Basics Open Source ☕

A welcoming collection of **simple, standalone Java programs** for students taking their first steps in programming and DSA. No external libraries, Maven, Gradle, frameworks, or dependencies are needed.

## Programs

| Topic | Examples |
| --- | --- |
| Basics | Even/odd, leap year, multiplication table, swapping two numbers |
| Arrays | Reverse array, sum, largest, smallest, even/odd count, left rotation |
| Sorting | Bubble sort, selection sort, insertion sort |
| Searching | Linear search, binary search |
| Strings | Reverse string, palindrome, vowels, word count |
| Numbers | Prime check, factorial, Fibonacci, reverse number, digit sum, Armstrong number |
| Patterns | Right triangle star pattern |

**26 runnable Java programs** organized by topic. Each class contains its own `main` method.

## Getting started

1. Install **Java JDK 8 or newer** and check with `javac -version`.
2. Clone this repository.
3. From the repository root, compile and run one example:

```bash
javac arrays/ReverseArray.java
java -cp arrays ReverseArray
```

Or try:

```bash
javac searching/BinarySearch.java
java -cp searching BinarySearch
```

Edit the example inputs inside `main` and rerun to learn how the algorithm behaves.
